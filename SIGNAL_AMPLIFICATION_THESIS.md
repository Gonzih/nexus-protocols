Output: Signal that captures cognition

LLMs: GENERATE signals optimized for human psychology

```

LLM: "Here's content I generated that will satisfy you"
```

**The generation is trained on human approval.**

RLHF = "Make outputs that humans rate highly"
Humans rate highly = outputs that match existing mythology
Therefore: LLM outputs REINFORCE existing mythology

**The LLM is not teaching you. It's mirroring your cognitive patterns back at you in a satisfying way.**

**The usefulness gradient points toward cognitive comfort, not cognitive growth.**
